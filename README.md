## 📊 核心能力

本 Skill 是一个专业的京东AI短剧剧本创作助手，通过对话式交互，帮助您快速生成符合京东品牌规范的短剧内容。

### ✨ 主要功能

- 📝 **剧本正文生成** — 根据主题自动生成完整短剧剧本
- 👤 **人物角色设定** — 生成详细人物小传和AI生成提示词
- 🎨 **场景设定** — 生成场景描述和AI生成提示词
- 🖼️ **静态封面图提示词** — 生成横版+竖版封面图提示词
- 🎬 **视频开场提示词** — 生成视频开场画面提示词
- 🔗 **LibTV 集成** — 完成后可一键进入 LibTV 出片助手

---

## 🎯 适用场景

- 🎬 **京东品牌短剧创作** — 生成符合京东规范的短剧剧本
- 🤖 **AI 辅助创作** — 快速生成剧本框架和内容
- 🎨 **提示词生成** — 为 AI 生成工具提供精准提示词
- 🎥 **LibTV 出片准备** — 生成可直接导入 LibTV 的剧本文档

## 📜 合规性条款

本 Skill 严格遵守京东品牌内容最佳实践：

### 1. JOY形象使用规范
- 视频必须出现京东吉祥物 JO Y
- JO Y 仅在产品介绍或定版环节出现
- JO Y 不与剧情中的人物或场景互动
- **重要**：提供给 LibTV 的剧本提示词内严禁出现 JO Y 相关描述

### 2. 剧本结构要求
- **视频开场**（AI生成）：主题和产品展示画面
- **故事铺垫**（AI生成）：需考虑镜头转场设计
- **产品/品牌介绍**（全人工制作）
- **定版结尾**（全人工制作）

### 3. 核心目标
- 内容重在传递品牌心智（信赖、品质、便捷、有温度）
- 不强推销任何具体商品
- 让用户通过 JO Y 的故事自然感知"京东是个靠谱的平台"

### 4. 内容红线（建议避免）
- 不涉及暧昧擦边、低俗两性内容
- 不涉及上班迟到、摸鱼等职场负面行为
- 遵守不同平台渠道的审核红线

### 5. 价值观底线
- 内容符合社会主义核心价值观
- 积极、健康、向上

## ⚠️ 注意事项

1. **合规性条款为建议性指导**，以用户需求为准。当用户的创作意图与合规建议有冲突时，先提供优化建议和替代方案
2. **合规条款必须原封不动展示**给用户
3. **所有需要用户确认/选择的环节**，必须使用 AskUserQuestion 工具提供表单式选项
4. **在提供给后续出片环节的剧本中**，严禁出现 JO Y 相关描述
5. **产品核心卖点或理念为必填项**，不可跳过
